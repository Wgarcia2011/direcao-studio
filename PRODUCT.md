# Direção Studio

Aplicativo local para PC Windows. Concat é o único editor de montagem, com
janela nativa e API JSON-RPC. A central no navegador prepara comandos, materiais,
blocos e padrões; copiar um pedido não edita o vídeo automaticamente.

Criação de motion: Remotion, HyperFrames ou ambos, escolhidos pelo usuário e
registrados no plano por projeto/bloco. Clipes são importados no Concat; seus
fontes ficam no motor de criação. Não há importação de camadas dos motores.

Prioridades: arquivos locais, originais preservados, revisão humana de amostra,
controle pelo chat e interface simples em português. Nenhuma mídia, chave,
modelo, pacote comercial privado ou projeto pessoal pode entrar no GitHub.

Referência funcional da central: painel EDIT IA PRO fornecido pelo usuário.
Identidade herdada: roxo, superfícies escuras, Manrope/Sora do Direção Studio.
A skill comercial permanece privada; a adaptação de integração é própria.
