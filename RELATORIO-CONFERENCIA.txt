INSTALAÇÃO NO OUTRO PC
1. Instale Git, Python (recomendado 3.11), Node 22+ e FFmpeg/FFprobe no PATH.
2. Abra PowerShell:

   git clone https://github.com/Wgarcia2011/direcao-studio.git
   cd direcao-studio
   powershell -ExecutionPolicy Bypass -File .\INSTALAR.ps1 -BaixarWhisper
   powershell -ExecutionPolicy Bypass -File .\INICIAR.ps1

3. Abra http://127.0.0.1:8765/editor.
4. Abra a mesma pasta no Claude Code. Peça para ler CLAUDE.md e operar
   pela CLI, com o servidor aberto em outro terminal.
5. Importe seus vídeos localmente. Clonar não transfere projetos antigos.
6. Gere uma amostra e confira imagem, áudio, cortes e leitura das legendas antes
   de aprovar a exportação do seu vídeo.

LIMITES DA CONFERÊNCIA
- A operação pelo terminal foi executada de ponta a ponta; uma sessão real de
  conversa com Claude Code no outro PC ainda precisa ser conferida ali.
- O teste sintético valida instalação e processamento, não a qualidade narrativa
  ou o resultado visual de um vídeo real. Não foi realizada nova revisão visual
  completa de todas as telas/presets desta distribuição.
- Na distribuição pública, a fonte de impacto copiada anteriormente do Windows
  foi substituída por Manrope com licença incluída. Confira a aparência das
  legendas; ela pode diferir da instalação original.
- DeepSeek não foi chamado de verdade; seus testes usam respostas simuladas.
- MODNet e aceleração GPU não foram revalidados neste ciclo. CPU foi validada
  na exportação; remoção de fundo precisa de modelo e conferência própria.
- Primeira renderização pode baixar o navegador. Instalação/downloads exigem
  internet; edição e transcrição usam os arquivos locais.
