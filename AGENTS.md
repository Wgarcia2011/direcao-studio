# Agentes — editor único Concat

Leia CLAUDE.md e docs/CLI.md. As regras de originais, histórico, revisão e
aprovação humana continuam válidas. Use apenas o motor e a API do Concat para
novas edições; o editor anterior permanece recuperável pelo Git e por arquivos
locais preservados. Seus comandos não se aplicam ao Concat.

Não aplique estilos nem renderize vídeos pessoais para testar código: use
fixtures sintéticas. Execute `python -m unittest discover -s tests -p 'test_*.py'`,
`python scripts/auditar-publicacao.py` e `python scripts/verificar-upstream.py`.
Para alterações no editor Rust siga editor/CONTRIBUTING.md.

O catálogo tipográfico e a direção editorial anteriores são referências
criativas arquivadas, não presets já implementados no Concat. Consulte suporte
real antes de prometer compatibilidade. Preserve a revisão de amostra antes
da exportação final pelo chat.
